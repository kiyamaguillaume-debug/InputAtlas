输入图谱 · InputAtlas v0.1.0-beta

完整解压后双击 InputAtlas.exe。Windows 10 22H2 x64 / .NET Framework 4.8。

首次启动自动创建新的本地数据库：%LOCALAPPDATA%\InputAtlas
数据保存在当前用户目录；本包未附带个人历史数据。

关闭窗口后后台继续采集。
停止全部后台：使用 PowerShell 运行 stop-background.ps1。
再次打开 InputAtlas.exe 恢复采集。

可选开机启动：使用 PowerShell 运行 install-startup.ps1。
移除开机启动：使用 PowerShell 运行 remove-startup.ps1。

任务栏显示默认关闭，可在“实时监控 / Live monitor”页面勾选。
Windows 11 任务栏嵌入显示仍需补充验证。

便携模式：启动前在程序旁建立空文件 portable.mode，数据保存到 data 子目录。
每个数据目录对应一套独立统计。请把整套程序放在可写入的本地目录。

Start InputAtlas.exe after extracting the entire archive.
The dashboard starts collection; closing its window leaves workers running.
Run stop-background.ps1 in PowerShell to stop collection.
Run install-startup.ps1 / remove-startup.ps1 to manage current-user startup.
Taskbar attachment is optional and disabled by default.
